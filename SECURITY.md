# Security Policy

The security of the SkyBarber project is our highest priority. We welcome reports of any security vulnerabilities you may discover in the application, backend, or infrastructure.

## Supported Versions

The following versions of the project are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | ✅ Supported        |
| < v1.0  | ❌ Not Supported    |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **PLEASE DO NOT create a public GitHub Issue.** Doing so may allow others to exploit the vulnerability before a patch is released.

Instead, please report security vulnerabilities directly via email to:
**gokceemirhan23@gmail.com**

In your email, please include:
* The type of vulnerability (e.g., XSS, SQL Injection, JWT flaw, etc.)
* Step-by-step instructions to reproduce the vulnerability
* Any information you have about the potential impact of the vulnerability

We are committed to responding to all security reports within 48 hours and will work to patch the issue and release a new version as quickly as possible. Thank you for your contributions.
