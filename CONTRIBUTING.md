# Contributing to SkyBarber

Thank you for your interest in contributing to the SkyBarber project! This project is a Full-Stack (Web & iOS) solution designed for modern barber/salon automation.

To keep our development process organized, please follow the guidelines and standards below.

## 🚀 How to Contribute

1. **Fork the Repository:** Fork the project to your own GitHub account.
2. **Create a New Branch:** Follow Git Flow standards and create a new branch.
   - For new features: `git checkout -b feature/your-feature-name`
   - For bug fixes: `git checkout -b fix/your-bug-name`
3. **Make Your Changes:** Write your code and stick to the existing architecture (MVVM, Clean Code principles).
4. **Test Your Code:** Ensure your new code does not break the existing system by testing it locally (Docker/Simulator).
5. **Commit Your Changes:** Keep your commit messages descriptive (e.g., `feat: added user profile picture upload`).
6. **Open a Pull Request (PR):** Submit your changes as a PR to the main repository. Detail what you have changed in the PR description.

## 🛠 Development Environment Setup

- **Web / Backend:** Requires Node.js, Express, and npm. Use `npm install` to install dependencies.
- **iOS:** Requires Xcode 15+ and Swift 5+. Dependencies are managed via Swift Package Manager (SPM).

## 📝 Coding Standards
- Follow the DRY (Don't Repeat Yourself) principle.
- For iOS SwiftUI usage, break Views down into smaller, reusable components.
- Do not include dead code or commented-out blocks in your Pull Requests.

Every contribution (bug report, documentation, code) is highly appreciated!
